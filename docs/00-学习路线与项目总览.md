# 00 · 学习路线与项目总览

这套教程把「视频去水印工具」从零到能用的全过程拆成 9 篇，按顺序读即可。它不是一个 AI 大模型项目——核心是**图像统计 + FFmpeg 滤镜 + 桌面壳**，思路清晰、代码量可控，非常适合用来练习「把一个小工具做成完整产品」。

---

## 一、这个项目最终做了什么

给一批短视频（典型是 720×1280 的竖屏 AI 生成视频）去掉右下角固定位置的平台水印，例如「即梦AI」「可灵」「剪映」这类角标：

- 自动找出水印框的位置，并给出**置信度**；
- 置信度低时提示人工确认，可在缩略图上直接改 `x / y / 宽 / 高`；
- 两种修复引擎：`delogo`（快）和 `inpaint`（纹理背景更自然）；
- 批量处理，保留原音频，控制输出画质；
- 提供**命令行**和**图形界面**两种入口，全部本地运行，不上传任何视频。

最终产物位于仓库根目录：

| 文件 | 角色 |
|---|---|
| `dewatermark.py` | 核心引擎 + 命令行入口（探测、定位、修复、批量调度） |
| `app.py` | 图形界面后端（pywebview 的 `js_api`） |
| `ui/index.html` | 图形界面前端（单文件 HTML/CSS/JS） |
| `启动界面.bat` | 双击打开 GUI |
| `去水印.bat` | 把文件拖到它上面，走命令行批处理 |
| `requirements.txt` | Python 依赖 |
| `README.md` | 面向使用者的说明书 |
| `docs/` | 本教程 |

## 三、先建立整体心智模型

```text
                    ┌──────────────────────────┐
   视频文件 / 目录  →  │ dewatermark.py（引擎）    │
                    │  ① probe   读元数据        │
                    │  ② detect  定位水印框      │
                    │  ③ process 修复 + 编码     │
                    └────────────┬─────────────┘
                                 │  Python 函数
   ┌─────────────────────────────┴───────────────────────────┐
   │                                                         │
命令行 main()                                  app.py 的 Api 类
直接调用引擎                                    后台线程调用引擎
                                                         │
                                                js_api / poll()
                                                         │
                                          ui/index.html（浏览器渲染）
```

三条关键设计原则贯穿全文：

1. **定位与修复解耦**：`detect_watermark()` 只负责给出框和置信度，`process_delogo()` / `process_inpaint()` 只管按框修图。这样既能先预览再处理，也能手动改框。
2. **界面不碰重活**：FFmpeg / OpenCV 都在 `app.py` 的后台线程里跑，前端只做 320ms 一次的轻量轮询，所以处理时窗口不会假死。
3. **对自动定位保持诚实**：算法给出置信度，低于阈值就标黄提示人工确认；拖放通道在 Windows/WebView2 下不稳定，产品层就干脆不承诺——宁可少一个功能，也不留一个「能拖但没反应」的坑。

## 四、阅读代码的小技巧

- `dewatermark.py` 里有清晰的分区注释：`基础工具` → `水印自动定位` → `处理引擎` → `批量框架`，配合本教程按区阅读即可。
- 想知道定位准不准，不要靠猜：`python dewatermark.py 视频.mp4 --dry-run --preview` 会生成绿框预览图。
- 想知道界面卡在哪：`app.py` 的 `_diag()` 会把关键事件写到 `%TEMP%\dewm_ui_diag.log`；命令行加 `--debug` 打开 WebView2 开发者工具。
- 教程里的代码片段都来自当前实现，行号会随改动漂移，请以函数名/注释为锚点。

准备好后，从 [01 环境准备与第一个视频](./01-环境准备与第一个视频.md) 开始。
