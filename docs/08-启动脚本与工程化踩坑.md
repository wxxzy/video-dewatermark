# 08 · 启动脚本与工程化踩坑

目标：理解两个 bat 入口的设计，并系统复盘这个项目里真实踩过的坑——这些经验往往比功能代码更值钱。

---

## 1. `启动界面.bat`：挑解释器 + 无黑窗

```bat
@echo off
chcp 936 >nul
setlocal
cd /d "%~dp0"

set "PY="
call :Probe "python"
call :Probe "py -3.11"
call :Probe "py -3"
...
for /f "delims=" %%i in ('%PY% -c "import sys,os;p=os.path.join(...' ) do set "PYW=%%i"
start "" "%PYW%" "%~dp0app.py"
exit /b 0

:Probe
if defined PY exit /b 0
%~1 -c "import cv2, webview" >nul 2>nul
if not errorlevel 1 set "PY=%~1"
exit /b 0
```

三个设计点：

1. **挑解释器**：依次试 `python` / `py -3.11` / `py -3`，选第一个同时装了 `cv2` 和 `webview` 的。避免「装了依赖却跑在另一个 Python 上」这种最常见问题。
2. **用 `pythonw.exe`**：GUI 程序不需要控制台，用 `pythonw` 启动才不会在桌面留一个黑框。同目录找不到 `pythonw.exe` 时退回 `sys.executable`。
3. **`chcp 936`**：让中文提示在简体中文控制台正确显示。

> bat 文件本身在本机保存为 GBK 编码，所以直接 Read 会看到乱码注释；实际运行没问题。教程里以逻辑为准。

## 2. `去水印.bat`：拖到文件上就能批处理

```bat
set "OUT=%~dp0output"
if not exist "%OUT%" mkdir "%OUT%"
%PY% "%~dp0dewatermark.py" %* -o "%OUT%" --recursive
```

- `%~dp0` 是 bat 所在目录，输出统一进 `output\`；
- `%*` 把拖进来的所有路径原样传给 Python；
- 固定加 `--recursive`，拖一个文件夹进去也会展开子目录；
- 探测解释器时只要求 `cv2 + numpy`（不需要 `webview`），因为命令行模式不依赖界面库。

这是最轻量的「图形化」：不用装 pywebview，把文件拖到 bat 上就算启动。

## 3. 踩坑清单（按出现顺序）

### 3.1 黑窗不断弹出

**现象**：`pythonw.exe` 启动界面后，每处理一个文件就闪一个控制台窗口。
**原因**：`subprocess.Popen/run` 默认继承/新建控制台。
**修复**：所有 ffmpeg/ffprobe 子进程调用加：

```python
NO_WINDOW = getattr(subprocess, "CREATE_NO_WINDOW", 0)
creationflags=NO_WINDOW
```

`explorer /select` 也改用 `Popen(..., creationflags=NO_WINDOW)`。

### 3.2 pywebview 启动卡死

**现象**：窗口出来但界面永久转圈。
**原因**：`Api.window` 公共属性被 JS 桥递归反射到 WebView2 原生对象。
**修复**：改成 `_window`，API 对象上不留任何原生对象引用。

### 3.3 Mock 抢先，真实数据不接管

**现象**：浏览器预览模式的数据和实际文件混在一起。
**原因**：桥接晚于 1.2s 的超时判断。
**修复**：监听 `pywebviewready`，桥就绪即 `adoptRealApi()`，并清理 Mock 数据；超时延长到 2.5s 作为兜底。

### 3.4 中文路径预览图写不出来

**现象**：`--preview` 在中文目录下无图片。
**原因**：`cv2.imwrite()` 在 Windows 对非 ASCII 路径支持差。
**修复**：

```python
ok, buf = cv2.imencode(".png", frame)
if ok:
    Path(dst_png).write_bytes(buf.tobytes())
```

绕开 OpenCV 的文件路径 handling，用 Python 自己写字节。缩略图的 base64 生成也走同一条 `imencode` 路线。

### 3.5 底部 UI 被裁切

**现象**：窗口高度小时底部按钮看不见。
**原因**：footer 是固定高度，日志区展开时撑开父容器。
**修复**：footer `flex:0 0 58px`，日志改为 `position:absolute` 向上浮层；设置栏 sticky 底部按钮独立占位。

### 3.6 一直弹「完成 4 个」

**现象**：处理结束后每 1.2s 弹一次完成提示。
**原因**：空闲心跳反复命中 `finished=True` 分支。
**修复**：前端 `runSeq / toastSeq` 配对，每轮只提示一次（见第 06 篇）。

### 3.7 拖放事件绑不上

**现象**：`DragEnter` 完全没反应。
**原因**：pythonnet 里 `getattr(obj, "add_DragEnter")(pyfunc)` 静默失败。
**修复**：必须用 `obj.DragEnter += handler`。另外要处理 `DragOver` 并设置 `e.Effect`，否则 Windows 拒绝放置；跨线程控件操作要 `BeginInvoke`。

**最终决定**：即便修好事件，路径传递在不同 WebView2 版本下仍不稳定，产品层放弃拖放，只保留按钮和 Ctrl+V。前端加 `preventDefault()` 防止误拖导致页面导航。

### 3.8 剪贴板导入为空

**现象**：`GetClipboardData(CF_HDROP)` 拿到 0 或无效句柄。
**原因**：64 位下 `restype` 没设成 `wintypes.HANDLE`，指针被截断。
**修复**：显式设置 `argtypes/restype`，用 `DragQueryFileW` 遍历路径。

### 3.9 定位置信度不足却没提示

**现象**：两个视频「没能正确处理」，实际是自动定位框偏了。
**修复**：
- 引入 `Detection.confidence`，`score/0.45`，低于 0.22 判失败；
- 界面低于 50% 标黄「待确认」，可点缩略图手动改框；
- 命令行打印告警并退保守比例框；
- 算法本身从「取最强块」改为「多候选 + 角落先验 + 形态 + 能量验证」，修掉横向扩张失控和背景亮边误选。

### 3.10 可变帧率导致音画不同步

**修复**：`probe()` 优先用 `avg_frame_rate`，`0/0` 时回退 `r_frame_rate`。

## 4. 工程化建议

### 4.1 目录结构

```text
video_dewatermark/
├── dewatermark.py        # 引擎，无 GUI 依赖
├── app.py                # GUI 后端
├── ui/index.html         # GUI 前端
├── docs/                 # 教程
├── requirements.txt
├── README.md
├── 启动界面.bat
└── 去水印.bat
```

保持「引擎 / 界面 / 文档」分离：命令行用户可以完全忽略 `app.py`，界面用户不需要理解批处理参数。

### 4.2 建议加入 `.gitignore`

```text
__pycache__/
*.pyc
output/
*.preview.png
```

避免把缓存、成品视频、预览图推到仓库里。

### 4.3 分发给他人的最小清单

1. Python 3.9+ 与 `pip install -r requirements.txt`
2. FFmpeg（带 ffprobe 更佳）
3. 整个项目目录
4. Windows 10/11（WebView2 预装）

如果对方机器没有 Python，需要另行打包（PyInstaller 打包 pywebview 应用要额外处理 WebView2 资源和 HTML 文件路径，超出本教程范围）。

## 5. 已知限制（诚实清单）

- 不支持会移动/滚动的水印与全屏平铺水印；
- 不支持把资源管理器文件拖进窗口；
- 关闭界面会中断处理，正在写的输出文件会不完整；
- 自动定位是启发式算法，对低对比度水印和复杂纹理背景会失效；
- 修复是插值重建，无法恢复被遮挡的原始像素。

把这些写进 README 不是示弱，而是让用户建立正确预期——比收到「怎么还有痕迹」的投诉好得多。
