# 01 · 环境准备与第一个视频

目标：在本机把工具跑起来，处理掉一个视频右下角的水印，并理解「ffmpeg 是怎么被找到的」。

---

## 1. 需要三样东西

| 组件 | 用途 | 缺失后果 |
|---|---|---|
| **Python 3.9+** | 跑引擎和界面 | 无法运行 |
| **FFmpeg（最好带 ffprobe）** | 解码、滤镜、编码 | 无法处理视频 |
| **opencv-python + numpy** | 自动定位、inpaint 引擎 | 仍可手动框处理，但自动定位不可用 |
| **pywebview** | 图形界面 | 只能用命令行 |

Windows 上图形界面还依赖 **WebView2 运行时**，Win10/11 基本预装；老系统需自行安装 Evergreen Runtime。

---

## 2. 安装 Python 依赖

在项目目录打开终端：

```bash
pip install -r requirements.txt
```

内容只有三行：

```text
numpy>=1.24
opencv-python>=4.8
pywebview>=5.0
```

验证：

```bash
python -c "import cv2, numpy, webview; print('deps ok')"
```

> 踩坑提示：如果 `pip install` 后仍然报 `ModuleNotFoundError`，多半是装到了另一个解释器。本项目的 bat 脚本会依次尝试 `python`、`py -3.11`、`py -3`，挑第一个同时装有 `cv2` 和 `webview` 的解释器——如果你有多个 Python，建议直接用 `py -3.11` 显式安装。

---

## 3. 安装 FFmpeg

推荐带 `ffprobe` 的完整构建，例如：

```bash
winget install Gyan.FFmpeg
```

装完重开终端，确认：

```bash
ffmpeg -version
ffprobe -version
```

### 引擎是怎么找到 ffmpeg 的

`dewatermark.py` 顶部的 `_find_ffmpeg()` 按以下顺序探测，命中第一个可用项就停：

1. 环境变量 `FFMPEG_PATH`
2. `%LOCALAPPDATA%\Microsoft\WinGet\Packages\Gyan.FFmpeg*\**\bin\ffmpeg.exe`（winget 版本，优先，因为带 ffprobe）
3. 常见固定路径 `C:\Program Files\ffmpeg\bin\ffmpeg.exe`、`C:\ffmpeg\bin\ffmpeg.exe`
4. `PATH` 里的 `ffmpeg`
5. `imageio-ffmpeg` 包自带的静态二进制（兜底，通常没有 ffprobe）

找到 ffmpeg 后，会在同目录找 `ffprobe.exe`；找不到就退回 `PATH` 里的 ffprobe；再找不到也能跑，只是拿不到精确时长，进度条会不准。

如果都找不到，会直接报错并提示你安装或设置 `FFMPEG_PATH`。手动指定示例：

```bash
set FFMPEG_PATH=C:\dev\ffmpeg\bin\ffmpeg.exe
python dewatermark.py video.mp4
```

## 4. 处理第一个视频

准备一个右下角带水印的 `video.mp4`，执行：

```bash
python dewatermark.py video.mp4
```

你会看到类似输出：

```text
ffmpeg : C:\Users\...\ffmpeg.exe
待处理 : 1 个文件    引擎: delogo

[1/1] video.mp4
    分辨率 720x1280  30.00fps  0:10  1.9MB
    自动定位: x=576 y=1226 w=129 h=41  (1.4s)

开始处理 1 个文件 ...
  [1/2] video.mp4
      完成 → video_dewm.mp4  (1.8MB, 12.3s)

全部结束：成功 1，失败 0，总耗时 12s
```

发生了什么：

- `probe()` 读出 720×1280、30fps、时长和音轨信息；
- `detect_watermark()` 在右下角 ROI 内找到水印框（本篇先会用，第 04 篇讲原理）；
- `process_delogo()` 用 FFmpeg 的 `delogo` 滤镜按框插值填充，再用 `libx264` 重新编码；
- 音轨能直接复制就 `-c:a copy`，否则转 AAC；输出文件名自动加 `_dewm` 后缀，不覆盖原片。

---

## 5. 先确认再处理：预览模式

自动定位不是万能的。处理前强烈建议看一眼框的位置：

```bash
python dewatermark.py video.mp4 --dry-run --preview
```

- `--dry-run`：只定位和生成预览，不写输出视频；
- `--preview`：在输出位置生成 `*.preview.png`，**绿框**是即将被修复的区域，红色覆盖是算法认为的水印笔画。

如果绿框偏了，跳过自动定位，直接手动给框：

```bash
python dewatermark.py video.mp4 --box 576,1226,129,41
```

`--box` 的格式是 `x,y,w,h`，单位是**最终分辨率下的像素**。可以传多次来指定多个水印框。

## 6. 图形界面（可选，但推荐试试）

双击仓库根目录的 **`启动界面.bat`**：

1. 点「添加视频」选文件，或点「文件夹」整目录导入；
2. 点「自动定位全部」，卡片上出现水印框和缩略图；
3. 点「开始处理」，底部进度条走完即可，再点「打开输出目录」。

也可以先直接用浏览器打开 `ui/index.html`——它会进入 **Mock 演示模式**，能看界面长什么样，但按钮不会真的处理视频。真正的桥接只有 `python app.py` 启动后才有。

> 当前版本**不支持**把资源管理器里的文件拖进窗口，请用「添加视频」按钮，或复制文件后在窗口里按 **Ctrl+V**。原因见第 08 篇。

## 7. 常见故障排查

| 现象 | 原因 | 解决 |
|---|---|---|
| `未找到 ffmpeg` | PATH 和常见位置都没有 | `winget install Gyan.FFmpeg`，或设 `FFMPEG_PATH` |
| `未安装 opencv-python` | 依赖没装或装错解释器 | 用 `py -3.11 -m pip install -r requirements.txt` |
| 处理完没有声音 | 原片音轨编码不在可复制白名单，或用了 `--no-audio` | 默认会转 AAC；检查是否传了 `--no-audio` |
| 定位结果离谱 | 水印对比度太低 / 背景太复杂 | 用 `--preview` 看框，再用 `--box` 手动指定 |
| 输出文件很大 | CRF 太小 | 调大 `--crf`（如 22） |
